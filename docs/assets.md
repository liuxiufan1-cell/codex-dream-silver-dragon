# 素材与设计

主题为「白银龙娘 · 月夜晶宫」。银白长发、淡紫眼睛、白色龙角、银饰、浅紫翼膜和鳞尾，配合夜空、云海、银白宫殿与淡紫水晶。

| 颜色 | 数值 | 用途 |
| --- | --- | --- |
| 夜蓝 | `#121725` | 阅读区和界面底色 |
| 银白 | `#DDE2F2` | 主要文字、细边框 |
| 淡紫 | `#B6A4E8` | 选中项、月光与水晶 |
| 冰蓝 | `#7ABBE4` | 少量焦点和状态高亮 |

完整配色见根目录 `palette.json`。

## 图层

`assets/layers/manifest.json` 采用 **1024×1536 逻辑坐标**。八层依次为尾巴、左翼、右翼、后发、核心身体、左袖、右袖、前发。`x/y/width/height/pivot/z/motion/duration` 定义位置、局部枢轴、顺序和动作。

正常眼睛在稳定的 `core.png` 中，半闭和闭眼使用两个共用 SVG 补片。左右翼和袖摆部分采用透明 PNG 的 SVG 镜像复用；后发 SVG 使用透明裁剪，`back-hair.png` 保留供重建。它们不是八张独立手绘成品，也不是 Live2D 或三维绑定。

首页为右侧全身，聊天页为低对比半身。动态背景用纯场景 `assets/art/moon-palace-background.png`；`static-theme/background.png` 已烘焙角色，不能拿它代替动态场景底图，否则会人物重影。

纯场景原始生成尺寸为 **1672×941**；静态背景和两张定稿概念排版输出为 **2560×1440**。导出尺寸不等于原始绘制分辨率。

左侧 V4 装饰位于 `assets/art/left-dragon-atmosphere-v4.png`，配合 `assets/ui/` 的龙角、翼、鳞片、鳞尾、肖像徽章和银结图标。相关生成与主题演绎素材只依其权利声明提供，不额外授予角色或原画商业授权。

# 紫晶白昼动态组件

## 白紫界面

`palette.json` 定义白色画布、白色面板、浅紫辅助面、深灰紫正文与紫色强调。`scripts/build-palette.mjs` 为预览生成共享变量，为严格静态主题生成字面量 CSS；动态构建内嵌同一变量表。修改配色后先构建。

首页保留真实宿主标题、输入框与快捷入口，使用左列海报式排版。右侧为新坐姿人物，背景为白色晶宫。聊天页保持稳定浅色阅读底面与代码区域，缩小右侧装饰；小于等于 1700 CSS 像素的聊天窗口与小于等于 1100 像素的首页隐藏人物。预览与宿主共享配色和人物素材，原生控件的内容与数量由客户端决定。

所有宿主覆盖限制在选中主题及组件自有根标记内，沿用原生 `properties` CSS 层，以便覆盖引擎社区层。装饰 inert、aria-hidden 且不接收指针事件。

## 人物与动态

八层共享 1024×1536 画布。新坐姿原图用互补遮罩分离发梢、袖摆、翼尾，保留固定主体；这些区域仅做亚像素小幅摆动。独立躯干遮罩做六秒轻呼吸，头脸与手脚不整体漂移。眼睑坐标按新面部标定，半闭与闭眼补片共用同一画布。

off / subtle / full 由宿主读取，系统减少动态优先。菜单、滚动、输入法组合、路由变化和后台时暂停或收敛动作。完整档不添加正文位移或整个人物缩放。

## 接入契约

主题 ID 保持 `silver-dragon-moon-palace`。可信 bundle 内嵌样式与素材；普通主题 ZIP 中不执行脚本。`integration/install-dynamic.mjs` 校验固定 NGO v1.9.0 Windows injector 后接入，支持安装前检查与恢复；工具同时校验生成 bundle 的 SHA256。

`window.__SILVER_DRAGON_MOON_PALACE__.inspect()` 与 `cleanup()` 保持兼容。清理移除自有节点、根标记、事件、观察器和计时器，重复挂载先清理旧实例。

真实路由和任务绑定继续使用可见公开锚点与结构化 preload 事件，保持线程、turn 与 epoch 校验。不读取聊天文字，不以停止按钮消失推断成功。未知身份保持未知；详见 [路由与任务绑定](runtime-memory-router.md)。

## 验证边界

逻辑测试、真实 Chromium 预览/宿主 DOM 样例、固定版本引擎的完整脚本编译分别验证不同层面。DOM 样例不是 Codex。Windows 真机显示、实际引擎持久注入及未来客户端兼容性仍需单独验收。

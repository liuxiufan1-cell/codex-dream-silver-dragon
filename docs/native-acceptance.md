# 测试范围与限制

当前项目为 **v1.0.0-beta.1 公开测试版**，功能和兼容性仍在验证。

## 可复现验证

`npm test` 使用真实组件代码、惰性 DOM 和虚拟时钟，检查：

- 眨眼、动作档位、菜单、输入法组合、后台与清理生命周期。
- 页面识别、线程身份、客户端别名、路由切换和过期事件隔离。
- 完成、失败、取消、审批及减少动态的状态逻辑。
- 独立模拟预览的状态切换和计时器取消。
- 发布白名单、素材引用、文档链接、版本、构建哈希和静态主题结构。

这些测试不启动客户端、不连接实际会话或读取账号配置。生成报告写入被忽略的 `reports/` 目录，不随源码提交或下载包分发。

## 限制

逻辑回归和离线检查不能证明所有平台、宿主、输入法、窗口尺寸或客户端版本兼容。图层边缘、眼部对齐、连续动画、可读性和真实任务绑定仍需在目标环境中人工验收。

`concepts/` 是离线概念排版，`preview/` 是模拟交互页面，两者均不作为实际客户端功能或稳定性证明。此测试版不发布特定设备的配置、运行记录或环境验收说明。

# 安装差异与测试范围

## 已确认的差异来源

旧版独立预览自行渲染模拟控件；静态 ZIP 只有背景与受限 CSS；动态组件需要额外宿主接入。旧版仅提供集成模板，未提供固定版本接入工具，因此「导入 ZIP」不能得到独立预览中的分层动画。这是源码确认的能力边界，并非对用户设备的现场诊断。

旧版配色、概念图、预览与动态宿主样式分别维护。beta.2 将配色统一为共享输入，替换暗色场景与站姿人物，并新增明确的动态安装检查、安装与恢复入口。

## 可复现验证

- `npm test`：眨眼、动作档位、菜单、IME、后台与清理，路由/线程/别名/过期事件隔离，模拟状态计时器与源码/素材/构建完整性。
- `npm run test:browser`：真实 Chromium 渲染；1280×720、1920×1080、2560×1440、853×480 与移动窄屏；首页/聊天页素材、配色、布局、动作开关、菜单、IME、系统减少动态及自有组件清理。
- 浏览器宿主 DOM 样例：加载同一内嵌 bundle，检查浅色、动画、输入可用及输入框几何位置稳定。该样例不是实际 Codex DOM 快照。
- `npm run test:engine`：指定官方 NGO v1.9.0 Windows 源码，复制到临时目录，验证精确版本、安装、重复安装、官方完整注入脚本编译、受限 CSS、动态 bundle 内嵌、恢复和未知修改拒绝。
- `npm run render:concepts`：导出真实模拟预览截图和静态备用背景，不再使用另一套离线概念图排版。

报告写入 `reports/`，不把运行日志或设备信息打入源码包。

## 待真机验收

当前环境为 Linux，没有可启动的 Windows Codex 客户端。尚未确认具体 Codex 版本、安装后的实际动画、系统缩放、原生输入法、代码语法颜色和长时间运行表现。

最终真机验收应在同一版本包下逐项比较首页、聊天、侧栏、设置、代码块、弹窗及输入框，覆盖 100% 与 150% 缩放；检查无人物重影、无错位眼睑、无点击遮挡、无旧任务补播，并确认恢复后原引擎可正常启动。未完成这些检查前保持测试版标记。

# beta.2 验证记录

本次改版为白紫坐姿动态皮肤。主要交付为构建 bundle 与固定版本 NGO 接入/恢复工具；静态 ZIP 为配套与备用。

| 验证层 | 结果 | 能证明的范围 |
| --- | --- | --- |
| 组件与模拟预览逻辑 | 75 项通过 | 动态生命周期、眨眼与暂停、线程及任务隔离 |
| Chromium 浏览器 | 28 项通过 | 多尺寸渲染、浅色配色、素材、动态开关、IME、菜单与减少动态 |
| NGO v1.9.0 官方源码副本 | 8 项通过 | 精确版本检查、安装、重复安装、动态注入脚本编译、受限 CSS、恢复及未知修改拒绝 |
| 发布检查 | 打包时执行 | 素材引用、文档链接、源码白名单、版本与 SHA256 |
| Windows Codex 真机 | 未执行 | 当前环境不能启动 Windows 客户端，具体客户端版本尚未确认 |

浏览器覆盖 1280×720、1920×1080、2560×1440、853×480、390×844。853×480 用于检查缩放后的小 CSS 视口，不能等同 Windows 150% 缩放真机验收。

首页与聊天页示意图来自同一模拟预览的实际 Chromium 截图。宿主 DOM 样例使用同一 bundle，验证颜色、输入与清理；它不是实际 Codex DOM 快照。眼睑正常/半闭/闭眼已导出检查。

源版本基线为 `9b37ac3`。适配 NGO v1.9.0，提交 `46d24a75de5781e99ada0ea880887ce62c870e12`。原始设备安装信息未知，因此不把已发现的预览/静态/动态能力差异写成对用户设备的确定诊断。

仍需按 [安装说明](installation.md) 在 Windows 环境核验安装后首页、聊天、设置、弹窗、代码、系统缩放与恢复，确认后再升级稳定版。

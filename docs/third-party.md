# 第三方关系

本主题的实验性集成模板参考 [EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose) 的宿主结构。

仓库提供主题组件、素材清单、独立预览和开发者集成模板，不分发 Codex 应用或完整第三方引擎。第三方软件、作品和商标遵循其自身权利与许可，本项目不重新授权这些内容。

模板不包含任何设备目录、安装快照或自动部署目标，不能直接当作通用安装器使用。测试版的实际适配由兼容宿主集成者自行验证。

角色素材为主题演绎所需的生成或衍生素材；原始参考图不随项目分发。素材的权利范围见根目录权利声明。

beta.2 接入基线固定为上述 NGO 项目的 Windows v1.9.0，精确提交和 injector 哈希见 `integration/compatible-host.json`。本仓库分发自有接入工具，不附带第三方引擎源码；测试只在用户显式指定的上游副本中执行。

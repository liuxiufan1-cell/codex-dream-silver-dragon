# 二维分层动作规范

本版为二维图层的轻微位移和旋转，头部和面部保持稳定。不是 Live2D 绑定，不提供转头、口型、全身动作或三维模型。

| 对象 | 目标周期 | 动作与约束 |
| --- | --- | --- |
| 身体／呼吸 | 约 6 秒 | 只在身体层做轻微起伏；脸部不随整页移动 |
| 前后发梢 | 约 7–9 秒 | 围绕根部小角度缓摆，遮挡根部接缝 |
| 袖摆 | 约 7–9 秒 | 小角度局部摆动，衣领和手部不漂移 |
| 翼尖 | 约 10–12 秒 | 围绕翼根微摆，避免脱离身体 |
| 尾尖 | 约 10–12 秒 | 缓慢摆动，保留鳞尾轮廓 |
| 眨眼 | 间隔约 5–8 秒 | 正常→半闭→闭眼→半闭→正常；眼部补片与面部坐标一致 |
| 执行中水晶光环 | 缓慢循环 | 仅在模拟执行状态显示，不遮挡交互 |
| 完成 | 一次短暂亮起 | 结束后归于静止，不持续闪烁 |
| 待确认／失败 | 静态 | 使用文字、图标和低饱和颜色，不循环闪烁 |

## 动态档位

- **关闭**：停止人物动作、眨眼和状态装饰循环，保留静态状态标签。
- **轻量**：保留低幅度、少量动作，以阅读为主。
- **完整**：启用已制作的局部分层微动，不扩大为完整表演。

实际图层的枢轴、遮挡顺序和动作参数以 `assets/layers/manifest.json` 与预览源码为准。独立图层都具有透明背景；布景使用单独场景层。父容器负责首页全身／聊天半身取景，子图层只负责微动。

## 自动收敛

菜单展开、滚动、输入法 `compositionstart` 到 `compositionend`、路由切换时收敛装饰，避免抢夺注意力。系统 `prefers-reduced-motion`、页面进入后台时限制或停止动画。状态始终以可读文字表达，不能仅依靠颜色和运动。

装饰容器应设为 `pointer-events: none`，无焦点、无按钮语义；动作只应用于装饰元素，正文、代码、滚动容器及输入框不得参与缩放或位移动画。验证时检查连续眨眼、循环接缝和页面切换后的控制状态；实际通过项记录在验收报告中，不以本规范代替测试证据。

# 坐姿人物动态规范

八层同画布，头、脸、龙角、手脚和躯干主体固定；局部躯干呼吸使用独立羽化遮罩。发梢、袖摆、翼尾只做亚像素级小幅摆动，避免互补切片接缝放大。眨眼使用按新面部标定的半闭/闭眼补片，每五至八秒一次，缺任一补片则停止眨眼。

| 档位 | 行为 |
| --- | --- |
| 关闭 | 停止人物动画、眨眼及动态任务反馈 |
| 轻量 | 约 45% 幅度，局部呼吸与轻微发梢/衣摆/翼尾动作 |
| 完整 | 同一局部动作的完整幅度，不移动正文或整个人物 |

系统减少动态优先于完整档。尊重宿主 character/status 开关；菜单、IME、滚动、换页与后台暂停或收敛动态。聊天页减少人物占比；窄屏隐藏人物。

真实 busy/streaming 可缓慢旋转光环；只有同一已绑定任务 active→completed 才短亮一次；失败和待确认使用静态提示。菜单/后台期间错过的完成效果直接舍弃，不补播。

浏览器模拟状态明确标注为模拟，不连接真实会话。动画关闭、暂停、路由变化、重注入与清理均有逻辑与浏览器检查；Windows 真机持续运行仍需验收。
